# Algorithm-Visualizer-in-Python


A Python project that demonstrates classic search and sorting algorithms step by step.

This project is designed to help me strengthen my Python skills while applying core computer science concepts such as searching, sorting, loops, indexing, and algorithmic efficiency.

## Current Features

### Linear Search

* Searches through a list one element at a time.
* Returns the index of the target value if found.

### Binary Search

* Searches a sorted list by repeatedly dividing the search range in half.
* Demonstrates the use of start, end, and middle indexes.

### Bubble Sort

* Sorts a list by repeatedly comparing neighbouring elements.
* Shows the list after each pass.
* Counts comparisons and swaps.
* Uses an early exit optimization if the list is already sorted.
